# Cotiviti Software Engineer Internship Assessment

This repository contains my submission for the Cotiviti Software Engineer Internship Assessment.

## Project Title

**Clinical Decision Making and Pattern Recognition in Health Care**
**A Retrieval-Augmented AI Assistant for Payment Integrity and HCC Coding Review**

## Project Overview

This project explores the use of Retrieval-Augmented Generation (RAG) to support payment integrity reviewers during HCC coding and claim review.

The proposed solution retrieves relevant clinical documentation, coding standards, and payer policies from trusted knowledge sources before generating evidence-based recommendations. The objective is to improve review efficiency, consistency, and explainability while maintaining human oversight.
